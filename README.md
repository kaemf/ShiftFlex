# ShiftFlex — График смен 2026–2027 (3 műszak)

Автономное веб-приложение (SPA) и комплект таблиц Excel для просмотра 3-сменного производственного графика (Венгрия, **3 műszak**) для бригад **A**, **B**, **C**.

Поддерживаются оба полугодия с мгновенным переключением в шапке сайта:
- **1 полугодие 2027** (`01.01.2027 – 30.06.2027`, 181 день, норма `Köt.` 124 дня / 992 часа)
- **2 полугодие 2026** (`01.07.2026 – 31.12.2026`, 184 дня, 129 рабочих смен)

---

## Возможности веб-приложения

- **Переключение полугодий**: `1П 2027 (Янв–Июн)` и `2П 2026 (Июл–Дек)` с сохранением выбранного периода и динамической ссылкой на скачивание Excel.
- **Фильтр по бригаде (`Все`, `A`, `B`, `C`)**:
  - Персональная подсветка смен `I` (06:00–14:00), `II` (14:00–22:00), `III` (22:00–06:00) и подсчет часов за полугодие.
- **3 режима отображения**:
  - **Календарь**: компактная сетка месяцев с колонкой номеров недель ISO (`Нед`) и нормой `Köt.` по каждому месяцу.
  - **Табель 6 мес**: точная цифровая копия оригинального венгерского листа `3 műszak` с параллельными месяцами, вертикально объединенными блоками недель, полосами праздников и строкой `Köt.`.
  - **Список**: быстрый поиск по датам, дням недели (`H`, `K`, `SZE`...) и праздникам с фильтрацией по типу дня.
- **Экспорт в календарь (`.ics`)**: сохранение выбранной смены в Apple Calendar / Google Calendar в один клик.
- **Темная и светлая темы** + установка как PWA на экран смартфона.

## Логика 3-недельной ротации и праздники

### Смены (хронологически по колонкам)
- **I смена (`Délelőtt`)**: `06:00 – 14:00` (Утро)
- **II смена (`Délután`)**: `14:00 – 22:00` (Вечер)
- **III смена (`Éjszaka`)**: `22:00 – 06:00` (Ночь)

### Цикл ротации (Утро → Ночь → Вечер)
- **Неделя 1** (нед. `1, 4, 7, 10, 13, 16, 19, 22, 25` / `27, 30, 33…`): `C | A | B`
- **Неделя 2** (нед. `2, 5, 8, 11, 14, 17, 20, 23, 26` / `28, 31, 34…`): `A | B | C`
- **Неделя 3** (нед. `53, 3, 6, 9, 12, 15, 18, 21, 24` / `29, 32, 35…`): `B | C | A`

### 1 полугодие 2027 (Январь–Июнь)
- **Нормы `Köt.`**: Янв `20 / 160`, Фев `20 / 160`, Мар `20 / 160`, Апр `22 / 176`, Май `20 / 160`, Июн `22 / 176`. Итого: **124 смены (992 ч)** у каждой бригады (`A`: 41/44/39, `B`: 39/41/44, `C`: 44/39/41).
- **Государственные праздники в будни**: `01.01` (Újév), `15.03` (Революция 1848 г.), `26.03` (Страстная пятница), `29.03` (Пасхальный понедельник), `17.05` (Духов день).
- **Праздники в выходные**: `28.03` (Пасха, Вс), `01.05` (Праздник труда, Сб), `16.05` (Троица, Вс). Рабочих суббот-отработок нет.

### 2 полугодие 2026 (Июль–Декабрь)
- **Государственные праздники**: `20.08` (День св. Иштвана), `23.10` (Революция 1956 г.), `25–26.12` (Рождество).
- **Отработки и мосты**: рабочая суббота `08.08` за `21.08`; рабочая суббота `12.12` за `24.12`.
- **Зимняя остановка (`Téli leállás`)**: `28–31.12` в табеле обозначены как `B | C | A`, фактически оформляются отпуском по *Szabadságos lap* (ст. 122 ТК Венгрии).
